# FindShape

Гра: програма називає фігуру — ти показуєш її пальцем. Влучив — фігура зеленіє й
підписується. Промахнувся — гра каже, у що саме ти влучив, і ціль лишається.

**Грати:** https://anatoliistepaniuk.github.io/FindShape/

## Головна ідея

Двіжок нічого не знає про те, що показує. Для нього рівень — просто список
багатокутників із назвами. Тому та сама гра працює і на карті країн, і на
органах людини, і на сузір'ях, і на деталях двигуна: змінюється лише файл.

## Формат рівня

Файл рівня — JSON-масив фігур:

```json
[
  {
    "name": "Іспанія",
    "polygons": [
      [[412, 600], [430, 610], [445, 590]]
    ]
  },
  {
    "name": "Італія",
    "polygons": [
      [[600, 520], [610, 540], [620, 585]],
      [[640, 600], [645, 610], [652, 604]]
    ]
  }
]
```

Правил всього три:

1. `name` — те, що гра напише у завданні. Воно ж ідентифікатор фігури.
2. `polygons` — шматки фігури. Італія — це материк плюс острови, тому багатокутників кілька.
3. Точка — це `[x, y]` у будь-якій системі координат. Двіжок сам знайде межі й впише все в екран.

Більше в файлі немає нічого: ні мов, ні кольорів, ні розмірів полотна. Масштаб,
палітру (сусідні фігури різного кольору), порядок питань і підписи двіжок
виводить сам із координат.

Поряд лежить `levels/schema.json` — JSON Schema. Двіжку вона не потрібна, вона
для редактора: VS Code підсвітить помилку в новому рівні ще до запуску гри.

## Як додати рівень

1. Поклади файл у `levels/`.
2. Додай рядок у `levels/index.json` — «назва в меню»: «файл»:

```json
{ "Європа": "europe.json", "Тіло людини": "body.json" }
```

Рівень можна відкрити напряму: `index.html?level=europe`.

## Як зробити рівень із карти

`tools/geojson2level.py` перетворює будь-який GeoJSON на файл рівня: проєктує
(Меркатор), обрізає по вікну координат, спрощує лінії, викидає надто дрібні
шматки.

```bash
python3 tools/geojson2level.py tools/ne_110m_countries.geojson \
  --window -25 45 34 72 --continent Europe --out levels/europe.json
```

`--window` — захід, схід, південь, північ. Решта параметрів: `--epsilon`
(наскільки грубо спрощувати), `--min-area` (з якої площі фігура ще варта того,
щоб її шукати), `--name-field` (звідки брати назву; типово `NAME_UK`),
`--skip` (викинути поіменно).

Готові рівні зроблені так:

```bash
# Європа
--window -25 45 34 72 --continent Europe
# Африка
--window -20 52 -36 38 --continent Africa
# Південна Америка
--window -82 -34 -56 13 --continent "South America"
```

## Локальний запуск

```bash
python3 -m http.server 8000
```

Далі http://localhost:8000. Просто відкрити `index.html` подвійним кліком не
вийде: браузер не дасть прочитати файли рівнів з диска.

## Дані

Контури країн — [Natural Earth](https://www.naturalearthdata.com/) (1:110m,
public domain). Українські назви — з поля `NAME_UK` того ж набору.
